# SwitchHostsR -- 产品需求文档与后期规划

## 1. 项目概览与愿景

### 1.1 项目简介

SwitchHostsR 是一款跨平台桌面应用，用于便捷地管理系统 hosts 文件。项目基于 **Tauri 2.x**（Rust 原生层）+ **Vue 3**（前端 UI 层）构建，支持 macOS、Windows 和 Linux 三大平台。

项目名称中的 "R" 代表 **Rust**，表明这是一个使用 Rust 重写底层能力的 SwitchHosts 替代方案。相比原版 SwitchHosts（基于 Electron），SwitchHostsR 具有以下技术优势：

- **更小的安装包体积**：Tauri 打包远小于 Electron
- **更低的内存占用**：Rust 原生后端 + WebView 前端
- **更强的安全性**：Rust 的内存安全保证 + 完善的 RBAC 权限系统
- **本地数据持久化**：SQLite + Diesel ORM，无需外部数据库依赖
- **双平台支持**：同时支持 Tauri 桌面端和 uTools 插件端

### 1.2 产品愿景

成为开发者日常工作中最高效、最安全、最易用的 hosts 文件管理工具。在保持轻量化的同时，提供企业级的用户管理、权限控制和审计日志能力，满足个人开发者和团队协作的双重需求。

### 1.3 竞品分析

| 竞品 | 技术栈 | 优势 | 劣势 | SwitchHostsR 差异化 |
|------|--------|------|------|-------------------|
| **SwitchHosts**（原版） | Electron + React | 成熟稳定、社区大、功能完整 | 安装包 ~80MB、内存占用 200MB+、无用户权限系统 | Tauri 轻量化（包体积 <15MB、内存 <80MB）、RBAC 权限、SQLite 持久化 |
| **iHosts**（macOS） | Swift 原生 | macOS 原生体验、App Store 分发 | 仅 macOS、付费、无团队协作 | 跨平台（macOS/Win/Linux）、免费开源、团队协作能力 |
| **Gas Mask**（macOS） | Objective-C | 轻量、支持远程 hosts | 仅 macOS、已停止维护 | 活跃维护、现代技术栈、更丰富的管理能力 |
| **HostsMan**（Windows） | .NET | Windows 原生、功能丰富 | 仅 Windows、UI 老旧 | 跨平台、现代 UI、Monaco 编辑器体验 |
| **手动编辑 /etc/hosts** | - | 无依赖 | 需 root 权限、无版本管理、易出错 | 可视化管理、一键切换、操作审计、版本追溯 |

**核心差异化定位**：在轻量化（Tauri）的基础上，提供原版 SwitchHosts 不具备的用户管理 + 权限控制 + 审计日志能力，兼顾个人与团队使用场景。

## 4. 功能需求

### 4.1 已实现核心功能（从代码分析）

以下功能已在代码中实现（部分功能前后端对接程度不同）：

#### 4.1.1 用户认证与授权系统

**后端已完整实现，前端已基本对接。**

- **用户注册**：支持邮箱+密码注册，用户名可选（`api/users.rs` -> `create_user`）
- **用户登录**：邮箱/用户名+密码登录，支持"记住我"选项（`api/users.rs` -> `user_login`）
- **三方登录**：支持 GitHub OAuth 登录（`pages/login/third-login.vue`，通过 Octokit API）
- **JWT Token**：双 Token 机制（Access Token + Refresh Token），支持令牌刷新（`auth/token.rs`）
- **会话管理**：完整的 Session 管理，支持会话过期检测（`auth/session.rs`）
- **RBAC 权限**：四级角色体系 -- SuperAdmin / Admin / User / Guest（`auth/roles.rs`）
- **细粒度权限**：22 种权限点覆盖用户、主机、主机组、日志、系统管理（`auth/mod.rs` -> `Permission` 枚举）
- **权限中间件**：宏级别的权限校验（`require_auth!`、`require_permission!`、`require_user_access!`）
- **密码安全**：bcrypt 哈希存储（`Cargo.toml` -> `bcrypt = "0.17.0"`）
- **前端路由守卫**：登录状态检测 + 7 天有效期自动续期（`router/index.ts`）

#### 4.1.2 Hosts 管理

**后端已完整实现，前端已基本对接。**

- **Hosts CRUD**：创建、读取、更新、删除 hosts 配置（`api/hosts.rs`）
- **状态切换**：一键启用/禁用 hosts 配置（`toggle_host_active`）
- **分页查询**：支持分页获取 hosts 列表（`get_hosts_page`）
- **搜索功能**：按关键词、分组、启用状态搜索 hosts（`search_hosts`）
- **导入/导出**：批量导入和导出 hosts 数据（`import_hosts` / `export_hosts`）
- **统计信息**：获取 hosts 的总数、活跃数等统计（`get_host_stats`）
- **Monaco 编辑器**：集成 Monaco Editor，支持 hosts 语法高亮（`components/editor/`）
- **实时编辑保存**：编辑器内容变化后防抖自动保存（`pages/hosts-list/index.vue` -> `onEditorChange`）

#### 4.1.3 主机组管理

**后端已完整实现，前端尚未完全对接。**

- **分组 CRUD**：创建、读取、更新、删除主机组（`api/host_groups.rs`）
- **组成员管理**：向组中添加/移除主机（`add_host_to_group` / `remove_host_from_group`）
- **组状态切换**：一键启用/禁用整个主机组（`toggle_group_active`）
- **组统计**：获取主机组的统计信息（`get_group_stats`）
- **分页搜索**：支持分页和关键词搜索主机组（`search_host_groups`）
- **关联关系**：通过 `host_group_relations` 表管理多对多关系

#### 4.1.4 操作日志系统

**后端已完整实现，前端已基本对接。**

- **日志记录**：自动记录所有操作（创建、更新、删除等）（`api/logs.rs`）
- **日志查询**：按用户、操作类型、目标类型、时间范围搜索（`search_logs`）
- **批量删除**：支持批量删除日志（`batch_delete_logs`）
- **日志清理**：按天数清理旧日志（`clean_old_logs`）
- **日志导出**：导出日志数据（`export_logs`）
- **日志统计**：获取日志统计概览（`get_log_stats`）
- **操作类型/目标类型枚举**：动态获取可用的操作类型和目标类型（`get_operation_types` / `get_target_types`）
- **前端展示**：管理后台中的日志列表，支持分页浏览（`pages/admin/logs.vue`）

#### 4.1.5 用户管理（管理后台）

**后端已完整实现，前端已基本对接。**

- **用户列表**：分页获取所有用户（`get_users` / `get_users_page`）
- **用户搜索**：按关键词、角色、状态搜索用户（`search_users`）
- **用户编辑/删除**：更新和删除用户（`update_user` / `delete_user`）
- **用户统计**：获取用户统计信息（`get_user_stats`）
- **用户名/邮箱唯一性校验**：注册前检查可用性（`check_username_availability` / `check_email_availability`）
- **前端展示**：管理后台中的用户数据表格，支持状态切换（`pages/admin/user.vue`）

#### 4.1.6 系统管理

**后端已完整实现，部分为桩实现。**

- **系统配置**：获取和更新系统配置（`get_system_config` / `update_system_config`）
- **健康检查**：系统健康状态检测（`health_check`）
- **日志清理**：系统级日志清理（`clean_logs`）
- **备份管理**：创建备份、获取备份列表、恢复备份（目前为简化的桩实现）
- **系统信息**：获取操作系统、内核、内存、CPU 等信息（`commands.rs` -> `get_system_info`）
- **服务重启**：重启服务功能（`restart_service`）

#### 4.1.7 文件操作

**后端已完整实现。**

- **文本文件读写**：读取和写入文本文件（`read_text_file` / `write_text_file`）
- **文件存在检测**：检查文件是否存在（`file_exists`）
- **目录操作**：创建目录、列出目录内容（`create_directory` / `list_directory`）
- **文件信息**：获取文件元数据（大小、修改时间等）（`get_file_info`）
- **文件删除**：删除文件（`delete_file`）

#### 4.1.8 系统托盘

**已实现。**

- **托盘常驻**：应用支持最小化到系统托盘（`ui/tray.rs`）
- **托盘菜单**：右键菜单包含"打开主页"和"退出"选项
- **点击激活**：左键点击托盘图标显示主窗口
- **关闭隐藏**：点击窗口关闭按钮时隐藏而非退出（`lib.rs` -> `CloseRequested`）
- **防止退出**：`ExitRequested` 事件中阻止应用退出

#### 4.1.9 应用设置

**前端已实现，部分功能为 UI 展示。**

- **通用设置**：主题切换（深色/浅色/跟随系统）、语言切换、写入模式（追加/覆盖）、选择模式（单选/多选）、托盘标题显示、启动时隐藏（`components/settings/views/general.vue`）
- **代理设置**：HTTP/HTTPS 代理配置（`useSettings.ts` -> `proxy`）
- **命令设置**：自定义命令配置（`useSettings.ts` -> `cmd`）
- **高级设置**：匿名数据发送开关、hosts 文件路径、数据存储路径（`useSettings.ts` -> `advanced`）
- **持久化存储**：设置通过 Pinia + pinia-plugin-persistedstate 自动持久化

#### 4.1.10 国际化（i18n）

**已实现。**

- **三语言支持**：中文简体（zh-cn）、英文（en）、日文（ja）
- **完整翻译覆盖**：所有 UI 文本均已国际化（`langs/` 目录）
- **Vue i18n 集成**：通过 `useI18n()` hook 在组件中使用

#### 4.1.11 平台抽象层

**已实现。**

- **Bridge 模式**：通过 `Bridge` 类抽象不同平台 API（`utils/bridge/bridge-class.ts`）
- **Tauri 适配**：封装 `@tauri-apps/api` 调用（`utils/bridge/tauri.ts`）
- **uTools 适配**：封装 uTools API 调用（`utils/bridge/utools.ts`）
- **统一调用**：`useBridgeFunc` 统一前端 API 调用方式

#### 4.1.12 单实例控制

**已实现。**

- **macOS/Linux**：通过 `pgrep` 检测已运行实例（`lib.rs` -> `is_another_instance_running`）
- **Windows**：通过 `tasklist` 检测已运行实例

#### 4.1.13 数据库层

**已完整实现。**

- **SQLite + Diesel ORM**：轻量级本地数据库
- **r2d2 连接池**：高效的数据库连接管理
- **数据库迁移**：通过 diesel_migrations 管理 schema 变更
- **5 张核心数据表**：users、hosts、host_groups、host_group_relations、logs
- **ServiceFactory 模式**：统一的服务工厂，注入各业务服务
