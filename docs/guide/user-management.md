# 用户管理

本章介绍 Switch Hosts R 的用户管理功能，包括用户账户、权限控制、团队协作等特性。

## 👥 用户系统概述

### 用户类型

Switch Hosts R 支持多种用户类型，满足不同的使用场景：

**单用户模式**
```
适用场景: 个人开发者
特点:
├─ 无需登录认证
├─ 所有功能完全开放
├─ 配置存储在本地
└─ 简单快速的使用体验
```

**多用户模式**
```
适用场景: 团队协作
特点:
├─ 用户账户管理
├─ 权限分级控制
├─ 配置共享机制
└─ 操作审计日志
```

### 用户角色

**系统管理员 (Admin)**
```
权限范围:
├─ 用户账户管理 (创建/删除/修改)
├─ 系统设置配置
├─ 全局权限控制
├─ 审计日志查看
├─ 数据备份恢复
└─ 插件管理
```

**配置管理员 (Manager)**
```
权限范围:
├─ 创建/编辑/删除配置
├─ 管理配置分组
├─ 批量操作配置
├─ 导入/导出配置
├─ 查看操作日志
└─ 管理团队配置
```

**配置编辑者 (Editor)**
```
权限范围:
├─ 创建/编辑配置
├─ 启用/禁用配置
├─ 查看配置内容
├─ 导出个人配置
└─ 查看基本日志
```

**配置查看者 (Viewer)**
```
权限范围:
├─ 查看配置列表
├─ 查看配置内容
├─ 导出配置文件
└─ 查看基本信息
```

## 🔐 用户认证

### 本地认证

**用户注册**
```
首次启动 → 创建管理员账户
用户名: admin
密码: ********
确认密码: ********
邮箱: admin@example.com (可选)
```

**登录流程**
```
启动应用 → 登录界面
├─ 用户名/邮箱
├─ 密码
├─ 记住登录状态 (可选)
└─ 自动登录 (可选)
```

**密码策略**
```
密码要求:
├─ 最少 8 个字符
├─ 包含大小写字母
├─ 包含数字
├─ 包含特殊字符 (推荐)
└─ 不能与用户名相同
```

### 外部认证 (企业版)

**LDAP/AD 集成**
```
配置参数:
├─ LDAP 服务器: ldap://company.com:389
├─ 基础 DN: dc=company,dc=com
├─ 绑定用户: cn=admin,dc=company,dc=com
├─ 用户搜索过滤器: (sAMAccountName={username})
└─ 组映射规则: CN=Developers → Editor
```

**SSO 单点登录**
```
支持协议:
├─ SAML 2.0
├─ OAuth 2.0
├─ OpenID Connect
└─ JWT Token
```

## 🔒 权限控制

### 基于角色的权限控制 (RBAC)

**权限矩阵**

| 功能 | Admin | Manager | Editor | Viewer |
|------|-------|---------|--------|---------|
| 用户管理 | ✅ | ❌ | ❌ | ❌ |
| 系统设置 | ✅ | ❌ | ❌ | ❌ |
| 创建配置 | ✅ | ✅ | ✅ | ❌ |
| 编辑配置 | ✅ | ✅ | ✅ | ❌ |
| 删除配置 | ✅ | ✅ | 🔶* | ❌ |
| 启用配置 | ✅ | ✅ | ✅ | ❌ |
| 查看配置 | ✅ | ✅ | ✅ | ✅ |
| 导出配置 | ✅ | ✅ | ✅ | ✅ |
| 批量操作 | ✅ | ✅ | ❌ | ❌ |
| 查看日志 | ✅ | ✅ | 🔶* | 🔶* |

*🔶 仅限自己创建的配置或基本日志*

### 细粒度权限控制

**配置级权限**
```
配置属性:
├─ 所有者: 创建者用户
├─ 可见性: 私有/团队/公开
├─ 编辑权限: 所有者/指定用户/用户组
├─ 使用权限: 所有者/指定用户/所有人
└─ 管理权限: 所有者/管理员
```

**分组权限**
```
分组管理:
├─ 分组创建者: 自动获得管理权限
├─ 分组成员: 可查看和使用配置
├─ 分组管理员: 可管理分组和配置
└─ 继承权限: 子分组继承父分组权限
```

**功能权限**
```
自定义权限:
├─ hosts.create: 创建配置权限
├─ hosts.edit: 编辑配置权限
├─ hosts.delete: 删除配置权限
├─ hosts.enable: 启用配置权限
├─ system.backup: 系统备份权限
├─ system.restore: 系统恢复权限
├─ logs.view: 查看日志权限
└─ users.manage: 用户管理权限
```

## 👥 团队协作

### 用户组管理

**创建用户组**
```
用户管理 → 用户组 → 新建组
组信息:
├─ 组名: 前端开发组
├─ 描述: 负责前端项目开发
├─ 组长: developer01
├─ 成员: developer02, developer03
└─ 权限: Editor 级别
```

**组权限继承**
```
权限层级:
用户个人权限 > 用户组权限 > 默认权限

示例:
├─ 用户A: Viewer (个人) + Editor (组) = Editor
├─ 用户B: Manager (个人) + Editor (组) = Manager  
└─ 用户C: 无个人权限 + Editor (组) = Editor
```

### 配置共享

**共享配置**
```
配置设置 → 共享设置
├─ 共享范围: 指定用户/用户组/全部用户
├─ 权限级别: 只读/可编辑/完全控制
├─ 有效期: 永久/指定日期
└─ 通知方式: 邮件/应用内通知
```

**协作编辑**
```
实时协作功能:
├─ 多人同时编辑
├─ 实时同步更改
├─ 冲突检测和解决
├─ 编辑历史记录
└─ 评论和讨论
```

### 团队工作流

**配置审批流程**
```
工作流设置:
1. 开发者创建配置
2. 提交审核申请
3. 团队负责人审批
4. 自动部署生效
5. 通知相关人员
```

**变更管理**
```
变更流程:
├─ 变更申请: 填写变更原因和影响范围
├─ 风险评估: 自动分析潜在风险
├─ 审批流程: 根据影响级别确定审批人
├─ 测试验证: 在测试环境验证变更
├─ 正式发布: 应用到生产环境
└─ 回滚计划: 准备快速回滚方案
```

## 🛡️ 安全最佳实践

### 密码安全

**密码策略**
```
强制要求:
├─ 定期更换密码 (90天)
├─ 不能重复使用最近5个密码
├─ 复杂度要求 (大小写+数字+符号)
├─ 账户锁定策略 (5次失败锁定30分钟)
└─ 密码提示问题设置
```

**两步验证 (2FA)**
```
支持方式:
├─ 短信验证码
├─ 邮箱验证码
├─ 身份验证器应用 (Google Authenticator)
├─ 硬件安全密钥 (YubiKey)
└─ 生物识别 (指纹/面部)
```

### 会话管理

**会话安全**
```
安全设置:
├─ 会话超时: 8小时无操作自动登出
├─ 并发限制: 同一用户最多3个活跃会话
├─ 设备绑定: 记住受信任设备
├─ 强制登出: 管理员可强制用户登出
└─ 会话加密: 所有会话数据加密传输
```

### 数据保护

**隐私保护**
```
数据处理:
├─ 最小权限原则: 仅授予必要权限
├─ 数据脱敏: 敏感信息自动脱敏
├─ 访问日志: 记录所有数据访问
├─ 数据备份: 定期备份用户数据
└─ 数据销毁: 用户注销后安全删除数据
```
