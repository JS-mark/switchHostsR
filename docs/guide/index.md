# 使用指南

欢迎使用 Switch Hosts R！这是一个现代化的 hosts 文件管理工具，基于 Tauri 2.x 和 Vue 3 构建，为开发者提供高效、安全的 hosts 文件管理体验。

## 🚀 快速开始

如果您是第一次使用 Switch Hosts R，建议按照以下顺序阅读文档：

1. [为什么选择 Switch Hosts R？](/guide/why) - 了解我们的设计理念和优势
2. [安装指南](/guide/installation) - 下载并安装应用程序
3. [基本使用](/guide/basic-usage) - 学习基础操作

## 📖 功能介绍

深入了解 Switch Hosts R 的各项功能：

- [Hosts 管理](/guide/hosts-management) - 创建、编辑和管理 hosts 配置
- [用户管理](/guide/user-management) - 用户权限和账户管理
- [日志查看](/guide/logs) - 查看操作历史和系统日志

## 🎯 核心特性

### 🚀 现代化桌面应用
- 基于 Tauri 2.x 构建，体积小巧、性能卓越
- 支持 Windows、macOS 和 Linux 系统
- 原生系统集成，提供流畅的用户体验

### ⚡️ 高效 Hosts 管理
- 快速切换不同的 hosts 配置方案
- 支持分组管理和批量操作
- 本地和远程 hosts 文件支持
- 自动刷新和同步功能

### 🛡️ 安全可靠
- 内置权限管理和备份机制
- 确保系统 hosts 文件的安全性
- 支持一键恢复和历史版本管理
- 操作日志完整记录

### 🎨 现代化界面
- 基于 Vue 3 和 Naive UI 构建
- 支持深色模式和主题切换
- 响应式设计，适配不同屏幕尺寸
- 直观的用户界面和交互体验

### 🔧 开发者友好
- 提供完整的 REST API 接口
- 支持命令行操作
- 方便集成到开发工具链
- 支持自动化流程

### 🌐 多语言支持
- 内置中文、英文、日文等多语言
- 为全球开发者提供本地化体验
- 支持自定义语言包
