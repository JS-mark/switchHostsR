# 基本使用

本指南将带您了解 Switch Hosts R 的基本操作，帮助您快速上手使用。

## 🚀 首次启动

### 欢迎界面

首次启动 Switch Hosts R 时，您会看到欢迎界面：

1. **语言选择**：选择您偏好的界面语言
2. **主题设置**：选择浅色、深色或跟随系统主题
3. **权限授权**：授予应用修改 hosts 文件的权限
4. **基本配置**：设置写入模式和自动备份选项

### 主界面介绍

```
┌─────────────────────────────────────────────────────────┐
│  Switch Hosts R                                    ⚙️ 📱 │

├─────────────────────────────────────────────────────────┤

│  ├─ 🔴 生产环境                                          │

├─────────────────────────────────────────────────────────┤
```

**界面元素说明：**
- **顶部工具栏**：设置、帮助、最小化等功能
- **左侧面板**：hosts 配置列表和分组管理
- **右侧编辑器**：hosts 内容编辑区域
- **底部状态栏**：当前状态和操作提示

## 📝 创建第一个 Hosts 配置

### 步骤 1：新建配置

1. **点击新建按钮**
   ```
   左侧面板 → 点击 "+ 新建" 按钮
   ```

2. **填写基本信息**
   ```
   名称：开发环境
   描述：本地开发使用的 hosts 配置
   类型：本地 Hosts
   ```

3. **选择配置类型**
   - **本地 Hosts**：手动编辑的静态配置
   - **远程 Hosts**：从远程 URL 同步的配置

### 步骤 2：编辑 Hosts 内容

在右侧编辑器中输入 hosts 规则：

```bash
# 开发环境配置
127.0.0.1    dev.example.com
127.0.0.1    api.example.com
192.168.1.100    staging.example.com

# 屏蔽广告域名
0.0.0.0    ads.example.com
0.0.0.0    tracker.example.com
```

**语法说明：**
- `IP地址 域名`：将域名解析到指定 IP
- `# 注释`：以 # 开头的行为注释
- `0.0.0.0 域名`：屏蔽域名访问

### 步骤 3：保存并启用

1. **保存配置**
   ```
   Ctrl+S (Windows/Linux) 或 Cmd+S (macOS)
   或点击保存按钮
   ```

2. **启用配置**
   ```
   点击配置名称前的开关按钮
   绿色表示已启用，灰色表示已禁用
   ```

## 🔄 切换 Hosts 配置

### 快速切换

**方式一：点击切换**
```
左侧列表 → 点击目标配置 → 自动切换
```

**方式二：快捷键切换**
```
Ctrl+1~9：切换到对应编号的配置
Ctrl+↑/↓：在配置间上下切换
```

**方式三：托盘菜单**
```
右键托盘图标 → 选择目标配置 → 快速切换
```

### 批量操作

**启用多个配置**
```
按住 Ctrl 键 → 点击多个配置 → 右键菜单 → 批量启用
```

**禁用所有配置**
```
工具栏 → 全部禁用 → 恢复系统默认 hosts
```

## 📁 分组管理

### 创建分组

1. **新建分组**
   ```
   右键左侧空白区域 → 新建分组 → 输入分组名称
   ```

2. **分组示例**
   ```
   📁 开发项目
   ├─ 🟢 项目A - 开发环境
   ├─ 🟡 项目A - 测试环境
   └─ 🔴 项目A - 生产环境
   
   📁 工具服务
   ├─ 🟢 代理服务器
   ├─ 🟢 DNS 服务器
   └─ 🔴 广告屏蔽
   ```

### 管理分组

**移动配置到分组**
```
拖拽配置 → 放置到目标分组 → 自动归类
```

**重命名分组**
```
右键分组名称 → 重命名 → 输入新名称
```

**删除分组**
```
右键分组名称 → 删除分组 → 确认操作
注意：分组内的配置会移动到根目录
```

## 🌐 远程 Hosts 配置

### 添加远程配置

1. **创建远程配置**
   ```
   新建 → 选择 "远程 Hosts" → 填写信息
   ```

2. **配置参数**
   ```
   名称：团队共享配置
   URL：https://example.com/hosts.txt
   刷新间隔：15分钟
   用户代理：SwitchHostsR/1.0
   ```

### 同步设置

**自动同步**
```
设置 → 远程同步 → 启用自动同步
同步间隔：1分钟 / 5分钟 / 15分钟 / 1小时
```

**手动同步**
```
右键远程配置 → 立即同步 → 获取最新内容
```

**同步状态**
- 🟢 同步成功
- 🟡 同步中
- 🔴 同步失败
- ⚪ 未同步

## ⚙️ 基本设置

### 写入模式

**覆盖模式**（推荐）
```
完全替换系统 hosts 文件内容
优点：配置干净，无冲突
缺点：会覆盖其他程序的 hosts 配置
```

**追加模式**
```
在系统 hosts 文件末尾追加内容
优点：保留其他程序的配置
缺点：可能产生冲突，难以管理
```

### 备份设置

**自动备份**
```
设置 → 备份恢复 → 启用自动备份
备份频率：每次修改时 / 每天 / 每周
保留数量：10个 / 30个 / 100个
```

**手动备份**
```
工具栏 → 备份 → 创建备份点
输入备份描述 → 确认创建
```

### 界面设置

**主题切换**
```
设置 → 外观 → 主题选择
- 浅色主题
- 深色主题  
- 跟随系统
```

**语言设置**
```
设置 → 语言 → 选择界面语言
- 简体中文
- English
- 日本語
```

## 🔧 故障排除

### 常见问题

**配置不生效**
```
1. 检查配置是否已启用（绿色状态）
2. 确认 hosts 语法是否正确
3. 清除浏览器 DNS 缓存
4. 重启网络服务
```

**权限问题**
```
1. 以管理员身份运行应用
2. 检查 hosts 文件权限
3. 关闭杀毒软件的实时保护
4. 添加应用到白名单
```

**同步失败**
```
1. 检查网络连接
2. 验证远程 URL 是否可访问
3. 检查防火墙设置
4. 尝试手动同步
```
