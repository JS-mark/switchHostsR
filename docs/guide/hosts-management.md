# Hosts 管理

本章将详细介绍 Switch Hosts R 的核心功能 - Hosts 文件管理，包括高级编辑、批量操作、导入导出等功能。

## 📝 高级编辑功能

### Monaco Editor 集成

Switch Hosts R 集成了 Monaco Editor（VS Code 的编辑器内核），提供专业的代码编辑体验：

**语法高亮**
```bash
# 注释显示为绿色
127.0.0.1    localhost          # IP 地址蓝色高亮
192.168.1.100    dev.example.com   # 域名橙色高亮
0.0.0.0    ads.tracker.com     # 屏蔽规则红色高亮
```

**智能提示**
- IP 地址格式验证
- 域名格式检查
- 常用配置自动补全
- 语法错误实时提示

**代码折叠**
```bash
# 开发环境配置 ▼
127.0.0.1    dev.api.com
127.0.0.1    dev.web.com
127.0.0.1    dev.admin.com

# 生产环境配置 ▶ (已折叠)

# 测试环境配置 ▼
192.168.1.200    test.api.com
192.168.1.200    test.web.com
```

### 编辑器功能

**多光标编辑**

```
Alt+Click：添加多个光标
```


## 🔧 Hosts 配置类型

### 本地 Hosts 配置

**静态配置**
```bash
# 基本格式：IP地址 域名 [别名]
127.0.0.1    example.com www.example.com
192.168.1.100    api.example.com

# IPv6 支持
::1    localhost
2001:db8::1    ipv6.example.com

# 端口指定（某些情况下）
127.0.0.1:8080    local.api.com
```

**动态变量**
```bash
# 使用变量（Switch Hosts R 扩展语法）
${LOCAL_IP}    dev.example.com
${DOCKER_IP}    container.service.com

# 条件配置
#if ENVIRONMENT=development
127.0.0.1    debug.example.com
#endif
```

### 远程 Hosts 配置

**HTTP/HTTPS 源**
```
URL: https://raw.githubusercontent.com/team/hosts/main/development.hosts
刷新间隔: 15分钟
用户代理: SwitchHostsR/1.0
超时时间: 30秒
```

**认证支持**
```
基础认证: username:password@host
Token 认证: Authorization: Bearer <token>
自定义头部: X-API-Key: <key>
```

**缓存策略**
```
本地缓存: 启用/禁用
缓存时间: 1小时/6小时/24小时
离线模式: 网络不可用时使用缓存
```

## 📤 导入导出功能

### 导出格式

**标准 Hosts 格式**
```bash
# 导出的 hosts 文件
# 生成时间: 2024-01-15 10:30:00
# 来源: Switch Hosts R

127.0.0.1    localhost
192.168.1.100    dev.example.com
```

**JSON 格式**
```json
{
  "version": "1.0",
  "exported_at": "2024-01-15T10:30:00Z",
  "configurations": [
    {
      "id": "dev-config",
      "name": "开发环境",
      "description": "本地开发配置",
      "content": "127.0.0.1 dev.example.com",
      "enabled": true,
      "group": "开发项目"
    }
  ]
}
```

**CSV 格式**
```
Name,Description,Content,Enabled,Group
开发环境,本地开发配置,"127.0.0.1 dev.example.com",true,开发项目
测试环境,测试服务器配置,"192.168.1.200 test.example.com",false,测试项目
```

### 导入来源

**文件导入**
```
支持格式:
- .hosts (标准 hosts 文件)
- .txt (纯文本)
- .json (Switch Hosts R 格式)
- .csv (表格格式)
- .xml (配置文件)
```

**剪贴板导入**
```
编辑 → 从剪贴板导入
自动识别格式并解析内容
支持多种格式的智能转换
```

**URL 导入**
```
文件 → 从 URL 导入
URL: https://example.com/hosts.txt
自动下载并导入配置
```

### 导入选项

**冲突处理**

```
遇到同名配置时:
```

**内容合并**
```
合并策略:
```

```javascript
function processHosts(content) {
  // 自动添加时间戳注释

// 动态 IP 解析
function resolveIP(hostname) {
  // 从环境变量或配置文件获取 IP
```
