## 🔄 从 v1.x 迁移

### 自动迁移

Switch Hosts R 2.0 提供自动迁移工具：

1. **配置迁移**：自动检测并导入 v1.x 的配置
2. **设置迁移**：保留用户偏好设置
3. **备份创建**：迁移前自动创建备份

### 手动迁移

如果自动迁移失败，可以手动迁移：

1. **导出 v1.x 配置**：
   ```bash
   # v1.x 配置位置
   # Windows: %APPDATA%\SwitchHosts
   # macOS: ~/Library/Application Support/SwitchHosts
   # Linux: ~/.config/SwitchHosts
   ```

2. **导入到 v2.0**：
   - 启动 Switch Hosts R 2.0
   - 选择「文件」→「导入配置」
   - 选择 v1.x 的配置文件

### 不兼容变更

- **配置文件格式**：从 JSON 升级到加密格式
- **插件系统**：v1.x 插件需要重新开发
- **API 接口**：完全重新设计的 REST API
