# 下载 Switch Hosts R

Switch Hosts R 是一款现代化的 Hosts 文件管理工具，基于 Tauri 2.x 和 Vue 3 构建，为开发者提供高效、安全、易用的 Hosts 管理体验。

## 最新版本

### v1.0.0 (2024-01-15)

**稳定版本** - 推荐所有用户使用

- 🎉 首个正式版本发布
- ✨ 完整的 Hosts 管理功能
- 🔒 增强的安全性和权限控制
- 🌍 多语言支持（中文、英文）
- 🎨 现代化用户界面

## 系统要求

### Windows
- **操作系统**: Windows 10 (1903+) 或 Windows 11
- **架构**: x64 (64位)
- **内存**: 最低 4GB RAM，推荐 8GB+
- **存储空间**: 至少 200MB 可用空间
- **权限**: 需要管理员权限修改 Hosts 文件

### macOS
- **操作系统**: macOS 10.15 (Catalina) 或更高版本
- **架构**: Intel x64 或 Apple Silicon (M1/M2)
- **内存**: 最低 4GB RAM，推荐 8GB+
- **存储空间**: 至少 200MB 可用空间
- **权限**: 需要管理员权限修改 Hosts 文件

### Linux
- **发行版**: Ubuntu 18.04+, Debian 10+, CentOS 8+, Fedora 32+
- **架构**: x64 (64位)
- **内存**: 最低 4GB RAM，推荐 8GB+
- **存储空间**: 至少 200MB 可用空间
- **依赖**: GTK 3.24+, WebKit2GTK 4.0+
- **权限**: 需要 sudo 权限修改 Hosts 文件

## 安装说明

### Windows 安装

1. **下载安装包**：选择适合的安装包格式
2. **运行安装程序**：双击下载的文件
3. **管理员权限**：安装过程中会请求管理员权限
4. **选择安装位置**：默认安装到 `C:\Program Files\SwitchHostsR`
5. **完成安装**：安装完成后可在开始菜单找到应用

#### 便携版使用
1. 下载便携版 ZIP 文件
2. 解压到任意目录
3. 运行 `SwitchHostsR.exe`
4. 首次运行时会请求管理员权限

### macOS 安装

1. **下载 DMG 文件**：选择适合您 Mac 的版本
2. **挂载镜像**：双击 DMG 文件
3. **拖拽安装**：将应用拖拽到 Applications 文件夹
4. **首次运行**：在 Launchpad 或 Applications 中找到应用
5. **安全设置**：首次运行可能需要在系统偏好设置中允许

#### 命令行安装
```bash
# 下载并安装
curl -L https://github.com/switchhosts/switchhosts-r/releases/download/v1.0.0/SwitchHostsR_1.0.0_universal.dmg -o SwitchHostsR.dmg
hdiutil attach SwitchHostsR.dmg
cp -R "/Volumes/SwitchHostsR/SwitchHostsR.app" /Applications/
hdiutil detach "/Volumes/SwitchHostsR"
```

### Linux 安装

#### Ubuntu/Debian (DEB)

## 更新说明

### 自动更新

Switch Hosts R 支持自动更新检查：

1. **检查更新**：应用会定期检查新版本
2. **通知用户**：发现新版本时会显示通知
3. **一键更新**：点击通知即可开始更新过程
4. **后台下载**：更新包在后台下载
5. **重启应用**：下载完成后重启应用完成更新

### 手动更新

如果需要手动更新：

1. 访问 [GitHub Releases](https://github.com/switchhosts/switchhosts-r/releases)
2. 下载最新版本的安装包
3. 运行安装包覆盖现有安装
4. 用户数据和配置会自动保留

### macOS

#### 手动卸载
1. 打开 Finder
2. 进入「应用程序」文件夹
3. 找到「SwitchHostsR.app」
4. 拖拽到废纸篓
5. 清空废纸篓

```bash
# 删除应用

rm -rf ~/Library/Preferences/com.switchhosts.switchhosts-r.plist
rm -rf ~/Library/Caches/com.switchhosts.switchhosts-r
```

#### 使用 Homebrew

```bash
brew uninstall --cask switchhosts-r
```

### Linux

## 故障排除

### 常见问题

#### 安装失败
- **权限不足**：确保以管理员身份运行安装程序
- **防病毒软件**：临时禁用防病毒软件或添加例外
- **磁盘空间**：确保有足够的磁盘空间
- **系统版本**：检查系统是否满足最低要求

#### 启动失败
- **权限问题**：确保应用有修改 Hosts 文件的权限
- **端口占用**：检查是否有其他应用占用相关端口
- **依赖缺失**：Linux 用户检查是否安装了必要的依赖

#### 更新失败
- **网络问题**：检查网络连接和防火墙设置
- **权限问题**：确保应用有写入权限
- **手动更新**：尝试手动下载并安装最新版本
