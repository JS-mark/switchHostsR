# SwitchHostsR 项目进度规划

> 最后更新时间: 2026-05-07

## 项目概述

**项目名称**: SwitchHostsR  
**项目类型**: 跨平台桌面应用（基于 Tauri + Vue3）  
**项目目标**: 现代化的 Hosts 文件管理工具，支持本地和远程 Hosts 管理  
**技术栈**: 
- 前端: Vue 3 + TypeScript + Naive UI + Monaco Editor
- 后端: Tauri (Rust)
- 状态管理: Pinia
- 国际化: vue-i18n

4. Code Review
5. 合并到主分支

- 提交前运行 `pnpm lint`
- 遵循 Vue 3 组合式 API 规范
